# UAT Test Cases / Test Scripts
**Project:** ChooNova Transcribe
**Version:** 1.0

## คำแนะนำสำหรับผู้ทดสอบ
*   เอกสารนี้เขียนด้วยภาษาที่เข้าใจง่าย (Business Language) ขอให้ผู้ทดสอบทำตามขั้นตอนในช่อง **ขั้นตอนการทดสอบ (Steps)** และสังเกตผลลัพธ์
*   หากผลลัพธ์ตรงกับช่อง **ผลลัพธ์ที่คาดหวัง** ให้ทำเครื่องหมายในช่อง ✅ **Pass**
*   หากเกิดข้อผิดพลาดหรือไม่ตรงตามคาดหวัง ให้ทำเครื่องหมายในช่อง ❌ **Fail** และจดบันทึกสิ่งที่เกิดขึ้นในช่องหมายเหตุ

## ส่วนที่ 1: การใช้งานผ่านหน้าเว็บไซต์ (Web UI)

### 📝 TC01: การถอดเสียงภาษาไทยจากไฟล์เสียง (Batch Transcription - Thai)
**เงื่อนไขเริ่มต้น:** เข้าสู่หน้าเว็บไซต์หลักของ ChooNova Transcribe และเตรียมไฟล์เสียงภาษาไทย (เช่น MP3)
| ขั้นตอนการทดสอบ | ผลลัพธ์ที่คาดหวัง | สถานะ (Pass/Fail) | หมายเหตุ / ผู้ทดสอบ |
| :--- | :--- | :---: | :--- |
| 1. ไปที่เมนู "อัปโหลดไฟล์เสียง" | หน้าเว็บแสดงฟอร์มสำหรับอัปโหลดไฟล์ | | |
| 2. เลือกไฟล์เสียงภาษาไทย และเลือกภาษาเป็น "Thai" (ถ้ามีให้เลือก) | ไฟล์ถูกแนบเข้าระบบ | | |
| 3. กดปุ่ม "เริ่มถอดเสียง" | ระบบแสดงสถานะว่ากำลังประมวลผล | | |
| 4. รอจนกระทั่งประมวลผลเสร็จสิ้น | ระบบแสดงข้อความภาษาไทยที่ถอดได้บนหน้าจอ | | |
| 5. ลองอ่านทบทวนข้อความที่ระบบถอดมา | ข้อความมีความถูกต้อง สอดคล้องกับไฟล์เสียงต้นฉบับ | | |

### 📝 TC02: การถอดเสียงภาษาอังกฤษ / ตรวจจับอัตโนมัติ (Auto-detect)
**เงื่อนไขเริ่มต้น:** เตรียมไฟล์วิดีโอ (MP4) หรือไฟล์เสียงที่มีคนพูดภาษาอังกฤษ
| ขั้นตอนการทดสอบ | ผลลัพธ์ที่คาดหวัง | สถานะ (Pass/Fail) | หมายเหตุ / ผู้ทดสอบ |
| :--- | :--- | :---: | :--- |
| 1. ไปที่เมนู "อัปโหลดไฟล์เสียง" และแนบไฟล์ภาษาอังกฤษ | ไฟล์ถูกแนบเข้าระบบ | | |
| 2. เลือกภาษาเป็น "English" หรือ "Auto-detect" | ระบบรับทราบการตั้งค่า | | |
| 3. กดปุ่ม "เริ่มถอดเสียง" | ระบบแสดงสถานะการประมวลผล (อาจใช้เวลาโหลดโมเดลเล็กน้อยในครั้งแรก) | | |
| 4. รอจนการประมวลผลเสร็จสิ้น | ระบบแสดงผลลัพธ์เป็นข้อความภาษาอังกฤษที่ถูกต้อง | | |

### 📝 TC03: การถอดเสียงแบบเรียลไทม์ (Real-time Transcription)
**เงื่อนไขเริ่มต้น:** คอมพิวเตอร์มีไมโครโฟนที่ใช้งานได้ และเบราว์เซอร์อนุญาตให้ใช้งานไมโครโฟนได้
| ขั้นตอนการทดสอบ | ผลลัพธ์ที่คาดหวัง | สถานะ (Pass/Fail) | หมายเหตุ / ผู้ทดสอบ |
| :--- | :--- | :---: | :--- |
| 1. ไปที่เมนู "ถอดเสียงแบบเรียลไทม์ (Real-time)" | หน้าเว็บแสดงปุ่มสำหรับเริ่มบันทึกเสียง | | |
| 2. กดปุ่ม "เริ่มบันทึก" (Start) และเริ่มพูดภาษาไทยใส่ไมค์ | ระบบขออนุญาตเข้าถึงไมโครโฟน (ถ้ายังไม่ได้อนุญาต) และเริ่มรับเสียง | | |
| 3. พูดไปเรื่อยๆ ประมาณ 3-4 ประโยค | ข้อความจะปรากฏขึ้นบนหน้าจอแทบจะทันที (ภายใน 1-2 วินาทีหลังพูดจบประโยค) | | |
| 4. กดปุ่ม "หยุดบันทึก" (Stop) | ระบบหยุดรับเสียงและประมวลผลประโยคสุดท้ายจนเสร็จสิ้น | | |

### 📝 TC04: การบีบอัดไฟล์วิดีโอ (Video Compression)
**เงื่อนไขเริ่มต้น:** เตรียมไฟล์วิดีโอที่มีขนาดค่อนข้างใหญ่
| ขั้นตอนการทดสอบ | ผลลัพธ์ที่คาดหวัง | สถานะ (Pass/Fail) | หมายเหตุ / ผู้ทดสอบ |
| :--- | :--- | :---: | :--- |
| 1. ไปที่เมนู "บีบอัดวิดีโอ" | หน้าเว็บแสดงฟอร์มอัปโหลดวิดีโอ | | |
| 2. อัปโหลดไฟล์วิดีโอและกดดำเนินการ | ระบบเริ่มกระบวนการบีบอัดวิดีโอ | | |
| 3. เมื่อเสร็จสิ้น ทำการดาวน์โหลดไฟล์ผลลัพธ์ | สามารถดาวน์โหลดไฟล์ได้ และขนาดไฟล์เล็กลง วิดีโอยังเล่นได้ตามปกติ | | |

## ส่วนที่ 2: การทดสอบสำหรับผู้ดูแลระบบและนักพัฒนา (API & System Config)

### 📝 TC05: การป้องกันการใช้งาน API โดยไม่ได้รับอนุญาต (API Security)
**เงื่อนไขเริ่มต้น:** ใช้เครื่องมือเช่น Postman หรือ cURL ในการยิง API
| ขั้นตอนการทดสอบ | ผลลัพธ์ที่คาดหวัง | สถานะ (Pass/Fail) | หมายเหตุ / ผู้ทดสอบ |
| :--- | :--- | :---: | :--- |
| 1. เรียกใช้งาน API `POST /v1/transcription/audio` โดย **ไม่ใส่** Header `x-api-key` | ระบบตอบกลับด้วยข้อผิดพลาด 401 หรือ 403 แจ้งว่าไม่อนุญาตให้เข้าถึง | | |
| 2. เรียกใช้งาน API เดิม แต่ใส่ `x-api-key` ที่ถูกต้อง | ระบบยอมรับคำขอ และประมวลผลไฟล์ได้สำเร็จ | | |

### 📝 TC06: การทดสอบระบบจัดการ VRAM โหมด Idle
**เงื่อนไขเริ่มต้น:** ตั้งค่าโหมดโมเดลเป็น "idle" และตั้ง Timeout ให้น้อยลง (เช่น 60 วินาที) ผ่านหน้าการตั้งค่า
| ขั้นตอนการทดสอบ | ผลลัพธ์ที่คาดหวัง | สถานะ (Pass/Fail) | หมายเหตุ / ผู้ทดสอบ |
| :--- | :--- | :---: | :--- |
| 1. อัปโหลดไฟล์เพื่อถอดเสียง 1 ครั้ง เพื่อให้ระบบโหลดโมเดลเข้าการ์ดจอ | ถอดเสียงได้สำเร็จ | | |
| 2. ปล่อยระบบทิ้งไว้ **โดยไม่มีการใช้งานใดๆ** จนเลยเวลา Timeout ที่ตั้งไว้ | - | | |
| 3. (สำหรับผู้ดูแล) ตรวจสอบ VRAM ของการ์ดจอ | VRAM ที่โมเดลจองไว้ถูกคืนให้กับระบบเรียบร้อยแล้ว | | |
| 4. ลองอัปโหลดไฟล์ถอดเสียงอีก 1 ครั้งทันที | ระบบทำการโหลดโมเดลกลับมาใหม่ (ใช้เวลาเริ่มต้นนิดหน่อย) และถอดเสียงได้สำเร็จ | | |
