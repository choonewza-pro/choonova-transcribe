# Business Requirements Document (BRD) & User Stories
**Project:** ChooNova Transcribe
**Version:** 1.0

## 1. บทนำ (Introduction)
เอกสารฉบับนี้รวบรวมความต้องการทางธุรกิจ (Business Requirements) และ User Stories สำหรับระบบ **Choonova Transcribe** ซึ่งเป็นระบบแปลงเสียงพูดเป็นข้อความ (Speech-to-Text) ที่รองรับภาษาไทยเป็นหลักด้วยโมเดล NeMo Typhoon ASR และภาษาอังกฤษด้วย faster-whisper

---

## 2. User Stories

### Epic 1: การแปลงเสียงเป็นข้อความ (Transcription)
*   **US1.1:** ในฐานะ **ผู้ใช้งานทั่วไป** ฉันต้องการอัปโหลดไฟล์เสียงหรือวิดีโอภาษาไทยผ่านหน้าเว็บไซต์ (Web UI) เพื่อให้ระบบแปลงเป็นข้อความได้อัตโนมัติ โดยที่ฉันไม่ต้องพิมพ์เอง
*   **US1.2:** ในฐานะ **นักพัฒนาซอฟต์แวร์** ฉันต้องการเรียกใช้ API ถอดเสียงผ่าน HTTP Request พร้อมแนบ `x-api-key` เพื่อนำบริการถอดเสียงไปเชื่อมต่อกับแอปพลิเคชันอื่นๆ ขององค์กรได้
*   **US1.3:** ในฐานะ **ผู้ใช้งานทั่วไป** ฉันต้องการใช้งานระบบถอดเสียงแบบเรียลไทม์ (Real-time) ผ่านไมโครโฟน เพื่อให้เห็นข้อความปรากฏขึ้นทันทีระหว่างที่กำลังพูด (Live Captioning)
*   **US1.4:** ในฐานะ **ผู้ใช้งานทั่วไป** ฉันต้องการให้ระบบสามารถถอดเสียงภาษาอังกฤษ หรือตรวจจับภาษาอัตโนมัติ (Auto-detect) ได้เมื่อฉันอัปโหลดไฟล์ที่เป็นภาษาอังกฤษ

### Epic 2: การจัดการทรัพยากรระบบ (Resource Management)
*   **US2.1:** ในฐานะ **ผู้ดูแลระบบ (System Admin)** ฉันต้องการกำหนดค่าการจัดการหน่วยความจำ (VRAM Mode) ของ AI โมเดล ให้อยู่ในโหมด `always` (โหลดค้างไว้) หรือ `idle` (คืนหน่วยความจำอัตโนมัติหลังไม่มีการใช้งาน) เพื่อให้สามารถบริหารจัดการทรัพยากรของ GPU ได้อย่างมีประสิทธิภาพ

### Epic 3: ฟีเจอร์เสริม (Utility Features)
*   **US3.1:** ในฐานะ **ผู้ใช้งานทั่วไป** ฉันต้องการบีบอัดไฟล์วิดีโอ (Video Compression) ผ่านระบบ ก่อนนำไปประมวลผลหรือดาวน์โหลด เพื่อลดพื้นที่จัดเก็บและเพิ่มความเร็วในการอัปโหลด

## 3. กฎเกณฑ์ทางธุรกิจ (Business Rules)
1.  **การเข้าถึง API:** ทุก Endpoint ที่เป็นเวอร์ชัน `/v1/` จะต้องมีการยืนยันตัวตนด้วย Header `x-api-key` เสมอ (ยกเว้น Web UI และ WebSockets ที่สามารถใช้งานได้โดยไม่ต้องมี Token)
2.  **การจัดการโมเดล:** เมื่อตั้งค่า VRAM Mode เป็น `idle` ระบบจะต้องคืนค่าหน่วยความจำ GPU (Clear VRAM) หากไม่มีคำขอเข้ามาเกินเวลาที่กำหนด (ค่าเริ่มต้น 900 วินาที)
3.  **ข้อจำกัดโมเดล:** 
    *   ภาษาไทย `th` จะถูกประมวลผลด้วยโมเดล `Typhoon ASR`
    *   ภาษาอังกฤษ `en` หรือ `auto` จะถูกประมวลผลด้วยโมเดล `faster-whisper` โดยจะถูกโหลด (Lazy-load) เมื่อมีการเรียกใช้งานครั้งแรกเท่านั้น
