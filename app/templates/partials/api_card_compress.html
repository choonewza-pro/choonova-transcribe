บีบอัดวิดีโอ (Video Compressor)

อัปโหลด MP4/MKV/MOV/WEBM เพื่อลดขนาดด้วย FFmpeg — ลดความละเอียด (คงอัตราส่วน) และ/หรือลดบิตเรต แบบ async คิว 1 ไฟล์ต่อครั้ง

FLOW ลำดับการทำงาน (Sequence Diagram) ▾
🧑 Client Browser / cURL
🖥️ FastAPI Server main.py
⚙️ Queue Dispatcher compress_queue_dispatcher
🎛️ FFmpeg worker subprocess
1
↓
Client ส่งไฟล์วิดีโอ + พารามิเตอร์ไปที่ POST /v1/media/compress/jobs upload
2
↓
Server บันทึกไฟล์ + สร้างงานใน SQLite (สถานะ queued) แล้วตอบกลับทันที 202 Accepted + job_id + ตำแหน่งคิว create_compress_job
3
↓
Queue dispatcher poll งานที่ค้างทุก 1 วิ หยิบงานเก่าสุด (FIFO) — บีบอัดพร้อมกันได้สูงสุด {{ max_concurrent|default(1) }} ไฟล์ (default 1) get_next_queued_compress_job
4
↓
Spawn worker subprocess python -m app.run_compress_job <job_id> <input> ... → อัปเดตสถานะ processing isolated worker
5
↓
Worker probe ด้วย ffprobe (ความละเอียด/ความยาว/มีเสียง) → สร้างคำสั่ง FFmpeg (scale คงอัตราส่วน, bitrate/CRF, encoder) แล้วรัน — progress % อัปเดตลง DB ทุก ~1 วิ -progress pipe:1
6
↓
FFmpeg เสร็จ → Worker ตรวจ output, บันทึก output_path/ขนาด/ความละเอียด ลง DB แล้วอัปเดตสถานะ completed 100% write terminal state
7
↓
ลบไฟล์ต้นฉบับทุกกรณี (สำเร็จ/ล้มเหลว/ยกเลิก/restart) — ไฟล์ output ถูกเก็บไว้ ตาม COMPRESS_RETENTION_HOURS แล้วถูกลบอัตโนมัติ (DB เก็บ record ไว้เสมอ) cleanup
8
↻
Client poll GET /v1/media/compress/jobs/{job_id} ทุก 2 วิ เพื่อดูคิว/ความคืบหน้า แล้วดาวน์โหลดผ่าน GET .../download polling
9
↓
(ไม่บังคับ) DELETE /v1/media/compress/jobs/{job_id} เพื่อยกเลิก — ยุติ FFmpeg ทันที + ลบงาน + ไฟล์ทั้งหมด cancel
POST /v1/media/compress/jobs ▾

สร้างงานบีบอัดวิดีโอแบบเบื้องหลัง คืน job_id + ตำแหน่งคิวทันที (HTTP 202)
target_width — ความกว้างเป้าหมาย px (คงอัตราส่วน, ห้ามขยายเกินต้นฉบับ) · 0 = ไม่ลด
bitrate_kbps — บิตเรตเป้าหมายของวิดีโอ · 0 = ใช้ CRF แทน
crf — คุณภาพ (1–51, default {{ default_crf|default(28) }}) · preset — ultrafast..veryslow
encoder — libx264 (default) หรือ nvenc (GPU ถ้า ffmpeg รองรับ)
ต้องระบุอย่างน้อยหนึ่งอย่าง: target_width หรือ bitrate_kbps
คิวเต็ม (มากกว่า {{ max_queued|default(5) }} งาน) → HTTP 429 · พื้นที่ดิสก์ไม่พอ → HTTP 507

cURL (Multipart Upload)
curl -X POST http://localhost:8830/v1/media/compress/jobs \
  -H "x-api-key: change-me-in-production" \
  -F "file=@video.mp4" \
  -F "target_width=1280" \
  -F "bitrate_kbps=2000" \
  -F "crf=28" \
  -F "preset=medium"
Response JSON (202 Accepted)
{
  "status": "accepted",
  "job_id": "b2c3d4e5-...",
  "filename": "video.mp4",
  "queue_position": 3,
  "queue_length": 4,
  "message": "Job created and enqueued for background video compression"
}

  -H "x-api-key: change-me-in-production"

GET /v1/media/compress/jobs/{job_id}/download ▾

ดาวน์โหลดไฟล์ MP4 ที่บีบอัดแล้ว (เฉพาะงานที่เสร็จสมบูรณ์) — คืน HTTP 410 หากไฟล์ถูกเคลียร์ตาม retention policy แล้ว

cURL Request
curl -o compressed.mp4 \
  "http://localhost:8830/v1/media/compress/jobs/b2c3d4e5-.../download?api_key=change-me-in-production"
DELETE /v1/media/compress/jobs/{job_id} ▾

ยกเลิก/ลบงาน: ยุติ worker subprocess ทันที (คืน CPU/GPU) ลบ record ออกจาก SQLite และลบไฟล์ทั้งหมดบนดิสก์ (ทั้ง input และ output)

cURL Request
curl -X DELETE http://localhost:8830/v1/media/compress/jobs/b2c3d4e5-... \
  -H "x-api-key: change-me-in-production"
