POST & GET /v1/audio/transcriptions & /v1/audio/translations
🤖 OpenAI-Compatible Drop-in API

ใช้งาน ChooNova Transcribe เป็น Drop-in Replacement ของ OpenAI Whisper API ทันที เพียงกำหนด base_url="http://localhost:8830/v1" รองรับ Python OpenAI SDK, Node SDK, Open WebUI, Obsidian, Speakr และ Third-party tools ทุกตัว

Endpoint Method คำอธิบาย
/v1/audio/transcriptions POST ถอดเสียงพูดเป็นข้อความตามภาษาต้นทาง (รองรับ model="whisper-1", "typhoon-asr")
/v1/audio/translations POST แปลเสียงพูดทุกภาษาเป็นภาษาอังกฤษ (English Translation)
/v1/models GET คืนรายชื่อโมเดลที่พร้อมให้บริการในระบบ
Python OpenAI SDK (Official Library)
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8830/v1",
    api_key="change-me-in-production"  # หรือค่าใน .env GATEWAY_API_KEY
)

# 1. Transcribe Audio
with open("meeting.mp3", "rb") as audio_file:
    transcript = client.audio.transcriptions.create(
        model="whisper-1",
        file=audio_file,
        response_format="verbose_json",  # "json", "text", "srt", "vtt", "verbose_json"
    )
print(transcript)

# 2. Translate Audio to English
with open("thai_speech.mp3", "rb") as audio_file:
    translation = client.audio.translations.create(
        model="whisper-1",
        file=audio_file
    )
print(translation.text)
cURL (OpenAI Header Standard)
# Transcribe to SRT
curl -X POST http://localhost:8830/v1/audio/transcriptions \
  -H "Authorization: Bearer change-me-in-production" \
  -F "file=@/path/to/sample.wav" \
  -F "model=whisper-1" \
  -F "response_format=srt"

# Translate to English
curl -X POST http://localhost:8830/v1/audio/translations \
  -H "Authorization: Bearer change-me-in-production" \
  -F "file=@/path/to/sample.wav" \
  -F "model=whisper-1"
