Client ส่งไฟล์พร้อมเปิด flag enable_diarization=true ไปที่ POST /v1/media/transcribe/jobs upload

Worker สกัดเสียง 16kHz WAV ด้วย FFmpeg — อัปเดตสถานะ extracting 10% ffmpeg
4
↓
กรณีภาษาไทย (th):
• Step A (ASR): GPU รัน Typhoon ASR สำหรับทุก chunk — อัปเดต transcribing 20–60%
• Step B (VRAM Reset): Worker ล้าง ASR ออกจาก VRAM เพื่อป้องกัน CUDA OOM
• Step C (Diarization): โหลด PyAnnote 3.1 ตรวจจับช่วงเสียงผู้พูด — อัปเดต diarizing 60–90%
• Step D (Overlap Match): แมปผู้พูดเข้ากับคำ/ประโยคด้วย Maximum-Overlap Algorithm typhoon+pyannote
5
↓
กรณีภาษาอังกฤษ/ผสม (en / auto):
• Step A (ASR): Faster-Whisper ถอดความ — อัปเดต transcribing 20–50%
• Step B (Alignment): wav2vec2 ทำ Phoneme Forced Alignment — อัปเดต aligning 50–70%
• Step C (Diarization): PyAnnote 3.1 ระบุผู้พูดและผูกเข้ากับคำ — อัปเดต diarizing 70–90% whisperx_pipeline
6
↓
Worker ประกอบข้อความพร้อมแท็กผู้พูด ([SPEAKER_00], [SPEAKER_01]) + สร้าง SRT คำบรรยายแบบระบุผู้พูด แล้วอัปเดตสถานะ completed 100% export_builder
7
↻
Client poll GET /v1/media/transcribe/jobs/{job_id} (ผลลัพธ์ใน result.segments จะมีคีย์ speaker ทุก segment) polling
POST /v1/media/transcribe/jobs ▾

สร้างงานถอดความแบบเบื้องหลังสำหรับไฟล์วิดีโอ MP4/MKV/MOV หรือไฟล์เสียงขนาดยาว (สูงสุด {% if max_upload_mb > 0 %}{{ max_upload_mb|int }}MB{% else %}ไม่จำกัดขนาด{% endif %}{% if max_media_duration_sec > 0 %} / {{ (max_media_duration_sec / 3600)|round(1) }} ชั่วโมง{% endif %}) ระบบประมวลผลใน subprocess แยกต่างหาก คืน job_id ทันที (HTTP 202)
target_chunk_sec / max_chunk_sec (ไม่บังคับ) กำหนดความยาวเป้าหมาย/สูงสุดต่อ chunk — default ตาม language ที่เลือก (th: 45/90, en/auto: 25/30)
เพดานขนาดไฟล์ตั้งค่าได้ผ่าน env MAX_UPLOAD_SIZE_MB (default 0 = ไม่จำกัด, เกิน → HTTP 413)

พารามิเตอร์ของ Request
พารามิเตอร์ ชนิด คำอธิบาย
file * File (Binary) ไฟล์วิดีโอ (MP4, MKV, MOV) หรือไฟล์เสียง (WAV, MP3, M4A, FLAC, OGG)
language string th (Typhoon, default), en (Whisper), auto (Auto-detect)
enable_diarization bool true / false (default false) — ตรวจจับและแยกแยะผู้พูด (Speaker Diarization)
target_chunk_sec float ความยาวเป้าหมายต่อ chunk (default: th=45s, en/auto=25s)
max_chunk_sec float ความยาวสูงสุดต่อ chunk (default: th=90s, en/auto=30s)
cURL (Multipart Upload)
curl -X POST http://localhost:8830/v1/media/transcribe/jobs \
  -H "x-api-key: change-me-in-production" \
  -F "file=@/path/to/long_video.mp4" \
  -F "language=th" \
  -F "enable_diarization=true" \
  -F "target_chunk_sec=30" \
  -F "max_chunk_sec=60"
Response JSON (202 Accepted)
{
  "status": "accepted",
  "id": "a1b2c3d4-e5f6-4a5b-9c0d-1e2f3a4b5c6d",
  "filename": "long_video.mp4",
  "language": "th",
  "enable_diarization": true,
  "message": "Job created and enqueued for long-form video transcription"
}

DELETE /v1/media/transcribe/jobs/{job_id} ▾

ยกเลิก/ลบงานถอดความ: ยุติ worker subprocess ทันที (คืน GPU/CPU) หากงานกำลังทำงานอยู่จะเปลี่ยนสถานะเป็น cancelled (Soft Cancel) แต่หากงานนั้นเสร็จสิ้น/ล้มเหลวไปแล้วจะลบข้อมูลออกจากฐานข้อมูล SQLite และลบไฟล์ชั่วคราวบนดิสก์ทั้งหมด

cURL Request
curl -X DELETE http://localhost:8830/v1/media/transcribe/jobs/a1b2c3d4-... \
  -H "x-api-key: change-me-in-production"
Response JSON (200 OK)
{
  "status": "success",
  "message": "Job a1b2c3d4-... deleted."
}
DELETE /v1/media/transcribe/jobs/{job_id}/media ▾

ลบเฉพาะไฟล์ media บนดิสก์เพื่อคืนพื้นที่เครื่อง แต่ยังคงบันทึกข้อความ/SRT/timestamps ไว้ในฐานข้อมูล

cURL Request
curl -X DELETE http://localhost:8830/v1/media/transcribe/jobs/a1b2c3d4-.../media \
  -H "x-api-key: change-me-in-production"
Response JSON (200 OK)
{
  "status": "success",
  "media_deleted": true,
  "message": "Media files deleted. Transcription record kept."
}
GET /v1/media/transcribe/jobs/{job_id}/export/{export_format} ▾

ดาวน์โหลดผลลัพธ์ของงานที่เสร็จสมบูรณ์แล้ว เป็นไฟล์ txt, srt (คำบรรยาย) หรือ json (พร้อม timestamps)

cURL Request
curl -X GET http://localhost:8830/v1/media/transcribe/jobs/a1b2c3d4-.../export/srt \
  -H "x-api-key: change-me-in-production" \
  -o transcript.srt
Supported Formats
export_format: txt | srt | json
Response (200 OK)
File stream (text/plain, text/plain, or application/json)
Response JSON (404 Not Found)
{
  "detail": "Job not found or transcription not completed."
}
