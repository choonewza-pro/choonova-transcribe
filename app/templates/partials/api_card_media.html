งานเบื้องหลังวิดีโอ/เสียงยาว (Long-form Media)

อัปโหลด MP4/MKV/MOV หรือไฟล์เสียงยาว (สูงสุด 1GB+ / 3+ ชั่วโมง) ประมวลผลแบบ async ใน subprocess

FLOW ลำดับการทำงาน (Sequence Diagram) ▾
🧑 Client Browser / cURL
🖥️ FastAPI Server main.py
⚙️ Worker Subprocess run_job.py → job_worker.py
🎛️ GPU ASR Typhoon / Whisper
1
↓
Client ส่งไฟล์วิดีโอ/เสียงแบบ multipart ไปที่ POST /v1/media/transcribe/jobs upload
2
↓
Server บันทึกไฟล์ลงดิสก์ + สร้างงานใน SQLite (สถานะ queued) create_job
3
↓
Server สร้าง worker subprocess python -m app.run_job <job_id> <input> <lang> แล้วตอบกลับ Client ทันที 202 Accepted + job_id async
4
↓
Worker สกัดเสียงด้วย FFmpeg (MP4 → 16kHz WAV) — อัปเดตสถานะ extracting 10% ffmpeg
5
↓
Worker ตัดแบ่งไฟล์เสียงตามช่วงเงียบเป็นหลาย chunk — อัปเดตสถานะ chunking 20% split_audio_silence
6
↓
Worker ส่งแต่ละ chunk เข้า GPU เพื่อถอดความทีละชิ้น — อัปเดตสถานะ transcribing 25–100% gpu_lock
7
↓
GPU คืนผลลัพธ์ (ข้อความ + word timestamps) ให้ Worker ต่อ chunk ไปเรื่อย ๆ จนครบ inference
8
↓
Worker รวมข้อความทั้งหมด + สร้างไฟล์ SRT + ลบไฟล์ชั่วคราว แล้วอัปเดตสถานะ completed 100% cleanup
9
↻
Client poll GET /v1/media/transcribe/jobs/{job_id} ทุก 2 วินาที เพื่อดูความคืบหน้า แล้วแสดงผลลัพธ์/ดาวน์โหลดผ่าน GET .../export/{txt|srt|json} polling
10
↓
(ไม่บังคับ) Client ส่ง DELETE /v1/media/transcribe/jobs/{job_id} เพื่อยกเลิก — Server ยุติ worker subprocess ทันที (คืน GPU/CPU) แล้วลบงาน + ไฟล์ชั่วคราว cancel
POST /v1/media/transcribe/jobs ▾

สร้างงานถอดความแบบเบื้องหลังสำหรับไฟล์วิดีโอ MP4/MKV/MOV หรือไฟล์เสียงขนาดยาว (สูงสุด 1GB+ / 3+ ชั่วโมง) ระบบประมวลผลใน subprocess แยกต่างหาก คืน job_id ทันที (HTTP 202)
target_chunk_sec / max_chunk_sec (ไม่บังคับ) กำหนดความยาวเป้าหมาย/สูงสุดต่อ chunk — default จาก env 30/60 วินาที

cURL (Multipart Upload)
curl -X POST http://localhost:8830/v1/media/transcribe/jobs \
  -H "x-api-key: change-me-in-production" \
  -F "file=@/path/to/long_video.mp4" \
  -F "language=th" \
  -F "target_chunk_sec=30" \
  -F "max_chunk_sec=60"
Response JSON (202 Accepted)
{
  "status": "accepted",
  "job_id": "a1b2c3d4-e5f6-4a5b-9c0d-1e2f3a4b5c6d",
  "filename": "long_video.mp4",
  "language": "th",
  "message": "Job created and enqueued for long-form video transcription"
}

DELETE /v1/media/transcribe/jobs/{job_id} ▾

ยกเลิก/ลบงานถอดความ: ยุติ worker subprocess ทันที (คืน GPU/CPU) ลบงานออกจากฐานข้อมูล SQLite และลบไฟล์ชั่วคราวบนดิสก์ทั้งหมดของงานนั้น

cURL Request
curl -X DELETE http://localhost:8830/v1/media/transcribe/jobs/a1b2c3d4-... \
  -H "x-api-key: change-me-in-production"
Response JSON (200 OK)
{
  "status": "success",
  "message": "Job a1b2c3d4-... deleted."
}
DELETE /v1/media/transcribe/jobs/{job_id}/media ▾

ลบเฉพาะไฟล์ media บนดิสก์เพื่อคืนพื้นที่เครื่อง แต่ยังคงบันทึกข้อความ/SRT/timestamps ไว้ในฐานข้อมูล

cURL Request
curl -X DELETE http://localhost:8830/v1/media/transcribe/jobs/a1b2c3d4-.../media \
  -H "x-api-key: change-me-in-production"
Response JSON (200 OK)
{
  "status": "success",
  "media_deleted": true,
  "message": "Media files deleted. Transcription record kept."
}
GET /v1/media/transcribe/jobs/{job_id}/export/{export_format} ▾

ดาวน์โหลดผลลัพธ์ของงานที่เสร็จสมบูรณ์แล้ว เป็นไฟล์ txt, srt (คำบรรยาย) หรือ json (พร้อม timestamps)

cURL Request
curl -X GET http://localhost:8830/v1/media/transcribe/jobs/a1b2c3d4-.../export/srt \
  -H "x-api-key: change-me-in-production" \
  -o transcript.srt
Supported Formats
export_format: txt | srt | json
