ถอดไฟล์เสียงแบบคิว (Audio Transcribe Jobs)

ส่งไฟล์เสียงเข้าระบบคิว (สูงสุด {{ max_audio_upload_mb|default(50)|int }}MB{% if max_audio_duration_sec > 0 %} / ความยาวไม่เกิน {{ (max_audio_duration_sec / 3600)|round(1) }} ชั่วโมง{% endif %}) ประมวลผลเบื้องหลัง แบบเดียวกับหน้า /v1/audio/transcribe (matrix โมเดลเดียวกัน) แต่ยกเลิกได้ + ดูประวัติที่หน้า "ประวัติการถอดความ"

2
↓
Server ตรวจสอบ: ประเภทไฟล์ (magic bytes), คิวเต็ม (429), พื้นที่ดิสก์ (507), โมเดลตรงกับภาษา/การระบุผู้พูด (422) แล้วบันทึกไฟล์ลง TEMP_JOBS_DIR/{job_id}/ + สร้างงานใน SQLite (สถานะ queued, type='audio', บันทึก model) create_job
3
↓
Server ตอบกลับทันที 202 Accepted + job_id + model — งานรอในคิว (สูงสุด {{ max_queued|default(10) }} งาน) async
4
↓
transcribe_queue_dispatcher (poll ทุก 1s) หยิบงานที่เก่าที่สุด แล้วสปอว์น subprocess python -m app.run_audio_job <job_id> <input> <lang> <model> <num> <min> <max> <diar> — รันพร้อมกันได้ไม่เกิน {{ max_concurrent|default(1) }} งาน (ยกเลิกได้ผ่าน DELETE → terminate + คืน GPU) dispatch
5
↓
Worker ตั้งสถานะ processing แล้วเรียก run_transcription() — โค้ดชุดเดียวกับ endpoint /v1/audio/transcribe (เลือก engine ตาม model + diarization) อัปเดตสถานะ transcribing transcribe
6
↓
Worker เขียนผลลัพธ์ลง SQLite: text, timestamps/segments, model, rtf, duration, processing_time แล้วตั้งสถานะ completed 100% write_result
7
↓
Worker ลบไฟล์ชั่วคราวใน TEMP_JOBS_DIR/{job_id}/ (ผลลัพธ์เก็บใน DB แล้ว — หน้า history แสดง "🗑 ถูกลบ") cleanup
8
↻
Client poll GET /v1/media/transcribe/jobs/{job_id} ทุก 2 วินาที (สถานะ/ความคืบหน้า) จนกว่าจะจบ polling
9
↓
ตัวเลือก: ยกเลิกงานได้ตลอดด้วย DELETE /v1/media/transcribe/jobs/{job_id} → ยุติ worker ทันที + ตั้งสถานะ cancelled cancel

เมื่อ completed — ดาวน์โหลดผลลัพธ์ผ่าน GET /v1/media/transcribe/jobs/{job_id}/export/{txt|srt|json} (หรือดูจากหน้า "ประวัติการถอดความ") export
POST /v1/audio/transcribe/jobs ▾

สร้างงานถอดเสียง (Multipart/form-data) — คืน 202 Accepted พร้อม id ทันที พารามิเตอร์เหมือน /v1/audio/transcribe (ดูการ์ด "ถอดไฟล์เสียง" ด้านล่าง): file, language, model, with_timestamps, enable_diarization, num_speakers, min_speakers, max_speakers — คิวเต็ม (≥ {{ max_queued|default(10) }}) → 429, ไฟล์เกิน {{ max_audio_upload_mb|default(50)|int }}MB{% if max_audio_duration_sec > 0 %} / ยาวเกิน {{ (max_audio_duration_sec / 3600)|round(1) }} ชั่วโมง{% endif %} → 413, โมเดลไม่ตรงกับภาษา/การระบุผู้พูด → 422

GET /v1/media/transcribe/jobs/{job_id} ▾

ตรวจสถานะงาน (status/stage/progress/result) — เดิมมีอยู่แล้วและใช้กับงานคิวเสียงได้เหมือนกัน

DELETE /v1/media/transcribe/jobs/{job_id} ▾

ยกเลิกงานที่กำลังทำงาน/รอคิว (ยุติ subprocess worker ทันที → คืน GPU) หรือลบงานที่เสร็จแล้ว

GET /v1/media/transcribe/jobs/{job_id}/export/{txt|srt|json} ▾

ดาวน์โหลดผลลัพธ์เป็น .txt / .srt (ซับไตเติล) / .json
