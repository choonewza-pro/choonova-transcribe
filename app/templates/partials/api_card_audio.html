ถอดไฟล์เสียง (Audio File Transcription)

แปลงไฟล์เสียงสั้น (สูงสุด {{ max_audio_upload_mb|default(50)|int }}MB, ตั้งค่าได้ผ่าน env MAX_AUDIO_UPLOAD_SIZE_MB) เป็นข้อความ รองรับภาษา ไทย/อังกฤษ/อัตโนมัติ

POST /v1/audio/transcribe ▾

แปลงไฟล์เสียงเป็นข้อความ (สูงสุด {{ max_audio_upload_mb|default(50)|int }}MB, เกิน → HTTP 413) รองรับการเลือกภาษา พร้อมสถิติเวลาและ Word Timestamps

พารามิเตอร์ model (บังคับ — เลือกเอนจิน)
ค่า เอนจิน ใช้กับภาษา
thai-whisper Thai Whisper (faster-whisper CT2) ไทย (แม่นยำสุด, มี word timestamps จริง)
typhoon Typhoon ASR (NeMo) ไทย (เร็วที่สุด)
whisper Faster-Whisper (large-v3-turbo) ไทย/อังกฤษ/อัตโนมัติ + แปล
whisperx WhisperX (ASR + Diarization) ระบุผู้พูดเท่านั้น (ไทย/อังกฤษ/อัตโนมัติ)

model ที่เลือกต้องสอดคล้องกับ language และ enable_diarization ไม่ตรง → HTTP 422:

language ไม่ระบุผู้พูด ระบุผู้พูด
th thai-whisper / typhoon / whisper thai-whisper / whisperx
en / auto whisper whisperx
translate (task) whisper
พารามิเตอร์อื่นๆ
  • language (str, default th) — th / en / auto
  • with_timestamps (bool, default true) — ส่งคืนตำแหน่งช่วงเวลาเริ่มต้น-สิ้นสุดระดับคำในอาร์เรย์ timestamps
  • enable_diarization (bool, default false) — ตรวจจับและแยกแยะผู้พูด (คืนฟิลด์ speaker เช่น SPEAKER_00 ในแต่ละคำ/ช่วงเวลา)
  • num_speakers (int, optional) — กำหนดจำนวนผู้พูดที่ทราบแน่นอน (เช่น 2) เพื่อความแม่นยำสูงสุดในการแยกแยะผู้พูด
  • min_speakers / max_speakers (int, optional) — กำหนดช่วงจำนวนผู้พูดต่ำสุด/สูงสุด
cURL (Multipart Upload)
curl -X POST http://localhost:8830/v1/audio/transcribe \
  -H "x-api-key: change-me-in-production" \
  -F "file=@/path/to/sample_audio.wav" \
  -F "language=th" \
  -F "model=thai-whisper" \
  -F "with_timestamps=true" \
  -F "enable_diarization=true" \
  -F "num_speakers=2"
Python (requests)
import requests

url = "http://localhost:8830/v1/audio/transcribe"
headers = {"x-api-key": "change-me-in-production"}

with open("sample_audio.wav", "rb") as f:
    files = {"file": f}
    data = {
        "language": "th",
        "model": "thai-whisper",
        "with_timestamps": "true",
        "enable_diarization": "true"
    }
    response = requests.post(url, headers=headers, files=files, data=data)

print(response.json())
