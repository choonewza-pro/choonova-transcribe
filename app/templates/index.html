ChooNova Transcribe API Service

ระบบแปลงเสียงพูดเป็นข้อความ (Speech-to-Text) ความเร็วสูง พร้อมรองรับ 2 ภาษาแบบดูอัล-เอนจิน:
Typhoon ASR Realtime (FastConformer-Transducer 114M) สำหรับภาษาไทย และ Faster-Whisper (CTranslate2) สำหรับภาษาอังกฤษ / ไทย-อังกฤษผสม

ความเร็วประมวลผล (RTFx)
4,000x+ RTFx
อัตราความผิดพลาด (CER)
0.0984 (90.1%+)
ขนาดโมเดล / VRAM
114M (< 1GB VRAM)
ภาษาที่รองรับ
ไทย / อังกฤษ / ผสม

เลือกโหมดใช้งานระบบ (Interactive Tools)

📁

1. ถอดไฟล์เสียง

แปลงไฟล์เสียง WAV, MP3, M4A, OGG หรือ FLAC เป็นข้อความ พร้อมตัวเลือก Word Timestamps และเลือกภาษา (ไทย/อังกฤษ/อัตโนมัติ)
🎙️

2. Real-time ไมค์

กดเปิดไมโครโฟน แล้วลองพูดภาษาไทยหรืออังกฤษ ระบบจะสตรีมเสียงผ่าน WebSocket และถอดความแสดงสดทันที
🎬

3. ถอดไฟล์เสียงและวีดีโอ

อัปโหลดวิดีโอ MP4, MKV, MOV หรือไฟล์เสียงขนาดยาว (สูงสุด 1GB+ / 3+ ชั่วโมง) ประมวลผลเบื้องหลังอัตโนมัติ
📚

4. ประวัติการถอดความ

เรียกดูงานที่เคยถอดความไว้ทั้งหมด พร้อม export เป็น .txt / .srt / .json และจัดการไฟล์ media
📊

ขีดความสามารถและข้อกำหนดของระบบ (Capabilities & Specifications)

สรุปสเปกการรองรับขนาดไฟล์ รูปแบบ อัตราสุ่มตัวอย่างเสียง และการเลือกเอนจิน

รายการสเปก (Specification) ขีดความสามารถและคำแนะนำ (Capabilities & Recommendations)
⚙️ การเลือกเอนจิน (Engine Routing) language=th → Typhoon ASR (ไทย) • language=en / auto → Faster-Whisper (อังกฤษ / ไทย-อังกฤษผสม)
📦 ขนาดไฟล์สูงสุด (Max Payload) 50 MB ต่อการอัปโหลด 1 ครั้งผ่าน REST API (POST /v1/transcribe) — ไฟล์ใหญ่กว่าใช้หน้า/endpoint งานเบื้องหลัง
⏱️ ความยาวไฟล์เสียงเดี่ยว (Max Duration) 15 - 30 นาที ต่อไฟล์ (แนะนำเพื่อความเร็ว) — ไฟล์ยาวใช้ POST /v1/transcribe/jobs
♾️ ความยาวสตรีมมิ่ง (WebSocket Limit) ไม่จำกัดความยาว (Unlimited) อัดสตรีมสดผ่าน WS /v1/stream ได้ต่อเนื่องตลอดเวลา
🎛️ ความถี่สัญญาณเสียง (Sample Rate) แนะนำ 16,000 Hz (16kHz), 16-bit Mono (ระบบมี Auto-Resampling หากเป็น 44.1kHz / 48kHz)
🎵 รูปแบบไฟล์ที่รองรับ (Formats) WAV MP3 M4A OGG FLAC AAC WEBM MP4 MKV MOV (MP4/MKV/MOV สำหรับงานเบื้องหลัง)

📚 วิธีการใช้งาน API Endpoints ทั้งหมด

เอกสารประกอบการเชื่อมต่อบริการ ChooNova Transcribe สำหรับนักพัฒนา (Developer API Reference)

🔑 การยืนยันตัวตน (Authentication)

บริการนี้ใช้ API Key ร่วมกับระบบ ChooNova AI โดยส่ง Header อย่างใดอย่างหนึ่งดังนี้:
• Authorization: Bearer <GATEWAY_API_KEY>
• x-api-key: <GATEWAY_API_KEY>
(ค่าเริ่มต้นช่วงพัฒนา: change-me-in-production)

GET /healthz

cURL Request
curl -X GET http://localhost:8830/healthz
Response JSON (200 OK)

  "status": "ok",
  "service": "typhoon-asr-service",
  "device": "cuda"
}

POST /v1/transcribe

แปลงไฟล์เสียงเป็นข้อความ (สูงสุด 50MB) รองรับการเลือกภาษา th (Typhoon ไทย) / en (Whisper อังกฤษ) / auto (Whisper ตรวจจับอัตโนมัติ), พร้อมสถิติเวลาและ Word Timestamps

cURL (Multipart Upload)
curl -X POST http://localhost:8830/v1/transcribe \
  -H "x-api-key: change-me-in-production" \
  -F "file=@/path/to/sample_audio.wav" \
  -F "language=en" \
  -F "with_timestamps=true"
Python (requests)
import requests

url = "http://localhost:8830/v1/transcribe"
headers = {"x-api-key": "change-me-in-production"}

with open("sample_audio.wav", "rb") as f:
    files = {"file": f}
    data = {"language": "auto", "with_timestamps": "true"}
    response = requests.post(url, headers=headers, files=files, data=data)

print(response.json())
Response JSON (200 OK)
{
  "status": "success",
  "text": "สวัสดีครับ นี่คือการทดสอบแปลงเสียงพูดเป็นข้อความด้วยไต้ฝุ่นเอเอสอาร์",

POST /v1/transcribe/jobs

สร้างงานถอดความแบบเบื้องหลังสำหรับไฟล์วิดีโอ MP4/MKV/MOV หรือไฟล์เสียงขนาดยาว (สูงสุด 1GB+ / 3+ ชั่วโมง) ระบบประมวลผลใน subprocess แยกต่างหาก คืน job_id ทันที (HTTP 202)

cURL (Multipart Upload)
curl -X POST http://localhost:8830/v1/transcribe/jobs \
  -H "x-api-key: change-me-in-production" \
  -F "file=@/path/to/long_video.mp4" \
  -F "language=th"
Response JSON (202 Accepted)
{
  "status": "accepted",
  "job_id": "a1b2c3d4-e5f6-4a5b-9c0d-1e2f3a4b5c6d",
  "filename": "long_video.mp4",
  "language": "th",
  "message": "Job created and enqueued for long-form video transcription"
}

GET /v1/transcribe/jobs/{job_id}/export/{export_format}

ดาวน์โหลดผลลัพธ์ของงานที่เสร็จสมบูรณ์แล้ว เป็นไฟล์ txt, srt (คำบรรยาย) หรือ json (พร้อม timestamps)

cURL Request
curl -X GET http://localhost:8830/v1/transcribe/jobs/a1b2c3d4-.../export/srt \
  -H "x-api-key: change-me-in-production" \
  -o transcript.srt
Supported Formats
export_format: txt | srt | json

WS /v1/stream

สตรีมไฟล์เสียงสดจากไมโครโฟนผ่าน WebSocket เพื่อถอดความเป็นข้อความสดแบบ Real-time (รองรับการส่ง query param ?api_key= หรือ subprotocol)

JavaScript Browser WebSocket Example
const socket = new WebSocket("ws://localhost:8830/v1/stream");

socket.onopen = () => {
  console.log("Connected to Realtime WebSocket");

  // Stream audio chunks (WebM/Opus or WAV PCM bytes)
  mediaRecorder.ondataavailable = (event) => {
    if (event.data.size > 0 && socket.readyState === WebSocket.OPEN) {
      socket.send(event.data);
    }
  };
  mediaRecorder.start(500); // Send chunk every 500ms
};

socket.onmessage = (event) => {
  const data = JSON.parse(event.data);
  console.log("Live Transcript:", data.text);
};

  "type": "partial",
  "text": "กำลังทดสอบพูดภาษาไทย...",
  "is_final": false
