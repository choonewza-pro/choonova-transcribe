เลือกโหมดใช้งานระบบ (Interactive Tools)

📁

1. ถอดไฟล์เสียง

แปลงไฟล์เสียง WAV, MP3, M4A, OGG หรือ FLAC เป็นข้อความ พร้อมตัวเลือก Word Timestamps และเลือกภาษา (ไทย/อังกฤษ/อัตโนมัติ)
🎙️

2. Real-time ไมค์

กดเปิดไมโครโฟน แล้วลองพูดภาษาไทยหรืออังกฤษ ระบบจะสตรีมเสียงผ่าน WebSocket และถอดความแสดงสดทันที
🎬

3. ถอดไฟล์เสียงและวีดีโอ

อัปโหลดวิดีโอ MP4, MKV, MOV หรือไฟล์เสียงขนาดยาว (สูงสุด {% if max_upload_mb > 0 %}{{ max_upload_mb|int }}MB{% else %}ไม่จำกัดขนาด{% endif %}{% if max_media_duration_sec > 0 %} / {{ (max_media_duration_sec / 3600)|round(1) }} ชั่วโมง{% endif %}) ประมวลผลเบื้องหลังอัตโนมัติ
📚

4. ประวัติการถอดความ

เรียกดูงานที่เคยถอดความไว้ทั้งหมด พร้อม export เป็น .txt / .srt / .json และจัดการไฟล์ media
🗜️

5. บีบอัดวิดีโอ

ลดขนาดไฟล์วิดีโอด้วย FFmpeg — ลดความละเอียด (คงอัตราส่วน) และ/หรือลดบิตเรต หรือตัดหัว-ท้าย (start/end) แบบคิวอัตโนมัติ 1 ไฟล์ต่อครั้ง
📂

6. ประวัติการบีบอัด

ดูผลการบีบอัด (ขนาด/ความละเอียด/อัตราการลด) และลบไฟล์ผลลัพธ์เองเพื่อประหยัดพื้นที่ดิสก์
⚙️

7. ตั้งค่าระบบ

จัดการ API Key และตั้งค่าโมเดลบน VRAM — เลือกโหมด always (จองถาวร) หรือ idle (ปล่อยเมื่อว่าง)
📊

ขีดความสามารถและข้อกำหนดของระบบ (Capabilities & Specifications)

สรุปสเปกการรองรับขนาดไฟล์ รูปแบบ อัตราสุ่มตัวอย่างเสียง และการเลือกเอนจิน

รายการสเปก (Specification) ขีดความสามารถและคำแนะนำ (Capabilities & Recommendations)
⚙️ การเลือกเอนจิน (Engine Routing) language=th → Typhoon ASR (ไทย) • language=en / auto → Faster-Whisper (อังกฤษ / ไทย-อังกฤษผสม)
📦 ขนาดไฟล์สูงสุด (Max Payload) {{ max_audio_upload_mb|default(50)|int }} MB ต่อการอัปโหลด 1 ครั้งผ่าน REST API (POST /v1/audio/transcribe) — ไฟล์ใหญ่กว่าใช้หน้า/endpoint งานเบื้องหลัง
⏱️ ความยาวไฟล์เสียงเดี่ยว (Max Duration) 15 - 30 นาที ต่อไฟล์ (แนะนำเพื่อความเร็ว) — ไฟล์ยาวใช้ POST /v1/media/transcribe/jobs
♾️ ความยาวสตรีมมิ่ง (WebSocket Limit) ไม่จำกัดความยาว (Unlimited) อัดสตรีมสดผ่าน WS /v1/realtime/stream ได้ต่อเนื่องตลอดเวลา
🎛️ ความถี่สัญญาณเสียง (Sample Rate) แนะนำ 16,000 Hz (16kHz), 16-bit Mono (ระบบมี Auto-Resampling หากเป็น 44.1kHz / 48kHz)
🗜️ การบีบอัดวิดีโอ (Video Compressor) ลดความละเอียด (คงอัตราส่วน) และ/หรือลดบิตเรต หรือ ตัดหัว-ท้าย (start/end) ด้วย FFmpeg ผ่าน POST /v1/media/compress/jobs — เอนจิน libx264 (CPU) หรือ NVENC (GPU) ประมวลผลแบบคิวอัตโนมัติ 1 ไฟล์ต่อครั้ง และลบไฟล์ต้นฉบับอัตโนมัติหลังเสร็จ
🎵 รูปแบบไฟล์ที่รองรับ (Formats) WAV MP3 M4A OGG FLAC AAC WEBM MP4 MKV MOV (MP4/MKV/MOV สำหรับงานเบื้องหลัง)
📚 วิธีการใช้งาน API Endpoints ทั้งหมด (คลิกเพื่อเปิด/ปิด)

เอกสารประกอบการเชื่อมต่อบริการ ChooNova Transcribe สำหรับนักพัฒนา (Developer API Reference) — คลิกที่แต่ละ endpoint เพื่อดูรายละเอียด
